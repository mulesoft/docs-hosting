= Managing Mule Apps Deployed to Hybrid Standalone Instances

Managing deployed Mule applications involves ongoing operations including monitoring, updates, configuration changes, and lifecycle management.

== Overview

Application management encompasses:

* Application lifecycle management
* Configuration and property management
* Performance monitoring and optimization
* Troubleshooting and diagnostics
* Updates and version management

== Application Lifecycle Management

=== Application States

Monitor and manage application states:

* *Started* - Application is running and processing requests
* *Stopped* - Application is deployed but not processing
* *Deploying* - Application deployment is in progress
* *Failed* - Application deployment or startup failed
* *Undeployed* - Application has been removed from the server

=== State Management

Control application states:

1. Navigate to Runtime Manager
2. Select *Applications* from the left menu
3. Choose the target application
4. Use state control actions:
   * *Start* - Begin application processing
   * *Stop* - Halt application processing
   * *Restart* - Stop and start the application
   * *Redeploy* - Deploy new version or configuration
