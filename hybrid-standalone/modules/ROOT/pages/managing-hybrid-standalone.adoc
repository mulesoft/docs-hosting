= Managing Hybrid Standalone Instances

This section covers the comprehensive management of your hybrid standalone runtime instances, including servers, server groups, and clusters.


== Managing Servers

Regular server management tasks include:

* Starting and stopping server instances
* Updating server configurations
* Monitoring server health and performance
* Managing server resources and capacity
* Applying security updates and patches

For details, refer to xref:managing-servers.adoc[Managing Servers].

=== Managing Server Groups and Clusters

For server groups and clusters:

* Adding or removing members
* Balancing workloads across instances
* Coordinating updates and maintenance
* Managing shared resources
* Monitoring collective health

For details, refer to:

* xref:managing-servers-groups.adoc[Managing Server Groups]
*  xref:managing-clusters.adoc[Managing Clusters].
