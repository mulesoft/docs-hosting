= Hybrid Standalone

Hybrid Standalone allows you to deploy and manage Mule applications on your own infrastructure while leveraging cloud-based management and monitoring capabilities through Anypoint Runtime Manager.

== Overview

Hybrid Standalone deployment provides the best of both worlds:

* **On-premises Control** - Deploy Mule applications on your own infrastructure
* **Cloud Management** - Manage and monitor applications through Anypoint Platform
* **Security Compliance** - Meet data residency and security requirements
* **Operational Flexibility** - Scale and configure based on your specific needs

== Key Benefits

=== Infrastructure Control

Maintain full control over your infrastructure:

* Deploy on your own servers or cloud instances
* Configure network security according to your policies
* Meet data residency and compliance requirements
* Integrate with existing infrastructure and monitoring tools

=== Cloud-Based Management

Leverage Anypoint Platform capabilities:

* Centralized application deployment and management
* Real-time monitoring and analytics
* Unified dashboard across hybrid and cloud deployments
* Automated alerts and notifications

=== Scalability and Performance

Optimize for your specific requirements:

* Scale horizontally by adding more servers
* Create server groups for load distribution
* Implement clusters for high availability
* Configure auto-scaling policies

== Architecture Overview

Hybrid Standalone architecture consists of:

* **Mule Runtime Engine** - Deployed on your infrastructure
* **Runtime Manager Agent** - Communicates with Anypoint Platform
* **Anypoint Platform** - Cloud-based management and monitoring
* **Runtime Manager** - Central management interface

== Getting Started

To begin with Hybrid Standalone:

1. **Plan Your Infrastructure** - Determine server requirements and network configuration

3. **Register with Runtime Manager** - Connect servers to Anypoint Platform

== Infrastructure Requirements

=== Server Requirements

Minimum server specifications:

* **CPU**: 2+ cores recommended
* **Memory**: 4GB RAM minimum, 8GB+ recommended
* **Storage**: 10GB available disk space
* **Network**: Reliable internet connectivity
* **OS**: Supported operating systems (Linux, Windows)

=== Network Requirements

Network configuration needs:

* Outbound HTTPS connectivity to Anypoint Platform
* Firewall configuration for Runtime Manager Agent
* Optional VPN for secure communication
* Load balancer configuration (for clustered deployments)

=== Security Considerations

Important security aspects:

* SSL/TLS encryption for all communications
* Certificate management and rotation
* Access control and authentication
* Network segmentation and firewall rules
* Audit logging and monitoring
