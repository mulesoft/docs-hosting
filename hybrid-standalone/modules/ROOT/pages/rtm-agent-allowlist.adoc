= Adding Ports, IPs, and Hostnames for Runtime Manager Agent

Configuring network access for the Runtime Manager Agent ensures secure communication between your hybrid standalone instances and the Anypoint Platform.

== Overview

Runtime Manager Agent (RTM Agent) network configuration involves:

* Understanding agent communication requirements
* Configuring firewall rules and allowlists
* Setting up network ports and protocols
* Managing secure connections
* Troubleshooting connectivity issues

== Network Architecture

=== Communication Flow

The RTM Agent communicates with Anypoint Platform through:

* *Outbound HTTPS connections* to Anypoint Platform services
* *WebSocket connections* for real-time monitoring
* *REST API calls* for management operations
* *Secure tunneling* for remote administration

=== Network Components

Key network components include:

* *Runtime Manager Agent* - Installed on each Mule server
* *Anypoint Platform Services* - Cloud-based management services
* *Load Balancers* - Traffic distribution and SSL termination
* *Firewalls* - Network security and access control
* *Proxy Servers* - Optional proxy for outbound connections

== Required Network Configuration

=== Outbound Ports

Configure outbound access for these ports:

* *Port 443 (HTTPS)* - Primary communication with Anypoint Platform
* *Port 5672 (AMQP)* - Message queue communication (if applicable)
* *Port 8883 (MQTT over SSL)* - IoT and event streaming (if applicable)
* *Port 22 (SSH)* - Secure remote access (if enabled)

=== Hostnames and Domains

Allow outbound access to these domains:

* *anypoint.mulesoft.com* - Primary Anypoint Platform domain
* *runtime-manager.anypoint.mulesoft.com* - Runtime Manager services
* *analytics.anypoint.mulesoft.com* - Analytics and monitoring services
* *eu1.anypoint.mulesoft.com* - EU region (if applicable)
* *gov.anypoint.mulesoft.com* - Government cloud (if applicable)

=== IP Address Ranges

Configure allowlist for Anypoint Platform IP ranges:

NOTE: IP addresses may change. Contact MuleSoft Support for current IP ranges.

* North America: Contact support for current ranges
* Europe: Contact support for current ranges
* Government Cloud: Contact support for current ranges

== Firewall Configuration

=== Outbound Rules

Configure outbound firewall rules:

[source]
----
# HTTPS traffic to Anypoint Platform
ALLOW tcp:443 to anypoint.mulesoft.com
ALLOW tcp:443 to runtime-manager.anypoint.mulesoft.com
ALLOW tcp:443 to analytics.anypoint.mulesoft.com

# WebSocket connections (if used)
ALLOW tcp:443 to ws.anypoint.mulesoft.com

# Regional endpoints (if applicable)
ALLOW tcp:443 to eu1.anypoint.mulesoft.com
ALLOW tcp:443 to gov.anypoint.mulesoft.com
----

=== Inbound Rules

Configure inbound access (if required):

* *Port 9999* - RTM Agent administration (internal network only)
* *Port 8080/8443* - Application endpoints (as needed)
* *Custom Ports* - Application-specific requirements

Implement network segmentation:

== Proxy Configuration

=== HTTP Proxy Setup

Configure HTTP proxy for outbound connections:

[source,properties]
----
# proxy.properties
http.proxyHost=proxy.company.com
http.proxyPort=8080
http.proxyUser=username
http.proxyPassword=password

https.proxyHost=proxy.company.com
https.proxyPort=8080
https.proxyUser=username
https.proxyPassword=password
----

=== Proxy Authentication

Configure proxy authentication:

* Basic authentication with username/password
* NTLM authentication for Windows environments
* Kerberos authentication for enterprise environments
* Certificate-based authentication

=== Proxy Bypass

Configure proxy bypass for internal resources:

[source,properties]
----
http.nonProxyHosts=localhost|127.*|[::1]|*.company.com|*.internal
----

== SSL/TLS Configuration

=== Certificate Management

Manage SSL certificates:

* Install trusted root certificates
* Configure certificate stores
* Manage certificate expiration
* Implement certificate rotation
* Validate certificate chains

=== SSL Configuration

Configure SSL settings:

[source,properties]
----
# SSL configuration
javax.net.ssl.trustStore=/path/to/truststore.jks
javax.net.ssl.trustStorePassword=changeit
javax.net.ssl.keyStore=/path/to/keystore.jks
javax.net.ssl.keyStorePassword=changeit
----

=== TLS Version Support

Configure TLS version requirements:

* TLS 1.2 minimum (recommended)
* TLS 1.3 support (preferred)
* Disable deprecated protocols (SSL 3.0, TLS 1.0, TLS 1.1)

== Agent Configuration

=== Network Settings

Configure agent network settings:

[source,yaml]
----
# mule-agent.yml
transports:
  websocket.transport:
    consoleUri: wss://runtime-manager.anypoint.mulesoft.com
  rest.agent.transport:
    port: 9999
    host: 0.0.0.0
----

=== Connection Timeouts

Configure connection timeout settings:

[source,yaml]
----
# Connection timeout configuration
connection:
  timeout: 30000
  readTimeout: 60000
  keepAlive: true
----

=== Retry Configuration

Configure retry behavior:

[source,yaml]
----
# Retry configuration
retry:
  maxAttempts: 3
  backoffMultiplier: 2
  initialDelay: 1000
----

=== Diagnostic Tools

Use diagnostic tools for troubleshooting:

[source,bash]
----
# Test connectivity
telnet anypoint.mulesoft.com 443
curl -I https://anypoint.mulesoft.com

# Check DNS resolution
nslookup anypoint.mulesoft.com
dig anypoint.mulesoft.com

# Test proxy connectivity
curl --proxy proxy.company.com:8080 https://anypoint.mulesoft.com
----
