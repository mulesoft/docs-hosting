= Monitoring Dashboard for Mule Apps Deployed to Hybrid Standalone

Monitoring dashboards provide centralized visibility into the performance, health, and business metrics of Mule applications deployed to hybrid standalone instances.

== Overview

Application monitoring dashboards offer:

* Real-time application performance visibility
* Business transaction monitoring and analysis
* Custom metric displays and visualizations
* Interactive data exploration capabilities
* Centralized application health monitoring

== Dashboard Types

=== Application Performance Dashboards

Monitor application-specific performance:

* Response time trends and distributions
* Throughput and transaction volume
* Error rates and failure analysis
* Resource utilization patterns
* Application health indicators

=== Business Metrics Dashboards

Track business-specific indicators:

* Transaction success rates
* Revenue and financial metrics
* Customer experience indicators
* SLA compliance monitoring
* Business process performance

=== Operational Dashboards

Monitor operational aspects:

* System resource utilization
* Infrastructure health status
* Deployment and version information
* Alert status and incident tracking
* Maintenance and uptime monitoring

== Runtime Manager Application Dashboards

=== Built-in Dashboard Features

Access standard application monitoring views:

* Application overview and status
* Performance metrics visualization
* Error tracking and analysis
* Log access and search capabilities
* Alert management integration

=== Navigation and Usage

Navigate application dashboards effectively:

* Application-specific dashboard access
* Multi-application comparative views
* Time range selection and filtering
* Metric drill-down capabilities
* Export and sharing options

=== Key Metrics Display

Monitor essential application metrics:

* *Throughput Metrics* - Messages/transactions per second
* *Response Time Metrics* - Average, median, 95th percentile
* *Error Metrics* - Error count, error rate, error types
* *Resource Metrics* - CPU, memory, connection usage
* *Availability Metrics* - Uptime, health check status
