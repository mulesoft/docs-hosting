= Managing Properties

Managing properties in hybrid standalone environments involves configuring, securing, and maintaining application properties and environment variables across your deployment infrastructure.

== Overview

Property management encompasses:

* Application property configuration
* Environment variable management
* Secure property handling
* Property inheritance and precedence
* Configuration lifecycle management

== Property Types

=== Application Properties

Manage application-specific configuration:

* *System Properties* - JVM and Mule runtime settings
* *Application Properties* - Custom application configuration
* *Environment Properties* - Environment-specific settings
* *Runtime Properties* - Dynamic runtime configuration
* *Integration Properties* - External system configuration

=== Environment Variables

Configure environment-specific variables:

* *Deployment Environment* - Development, staging, production
* *Infrastructure Settings* - Database connections, service URLs
* *Feature Flags* - Enable/disable application features
* *Performance Settings* - Timeouts, pool sizes, cache settings
* *Security Configuration* - API keys, certificates, tokens

=== Secure Properties

Handle sensitive configuration data:

* *Passwords and Secrets* - Database passwords, API keys
* *Certificates* - SSL certificates and private keys
* *Tokens* - Authentication and authorization tokens
* *Encryption Keys* - Data encryption configuration
* *Private Configuration* - Proprietary system settings

== Property Configuration in Runtime Manager

=== Setting Application Properties

Configure properties through Runtime Manager:

1. Navigate to Runtime Manager
2. Select the target application
3. Click on the *Properties* tab
4. Add or modify properties:
   * Key-value pairs
   * Property descriptions
   * Property types (String, Number, Boolean)
5. Save configuration changes
6. Restart application if required

=== Environment Variables

Manage environment variables:

1. Access application settings
2. Navigate to *Environment Variables* section
3. Configure variables:
   * Variable name and value
   * Environment-specific overrides
   * Variable descriptions
4. Apply changes to target environments

=== Property Sources

Configure property source precedence:

1. *System Properties* - Highest precedence
2. *Environment Variables* - Operating system level
3. *Application Properties* - Application-specific files
4. *Default Properties* - Built-in default values

=== Secure Property Files

Manage secure property files:

[source,properties]
----
# secure.properties
database.password=![encrypted_value]
api.key=![encrypted_value]
----

Configure secure property provider:

[source,xml]
----
<secure-properties:config name="Secure_Properties_Config" 
    file="secure.properties" 
    key="encryption.key" />
----

== Property Inheritance and Override

=== Property Hierarchy

Understand property precedence:

1. *Command Line Arguments* - Highest priority
2. *System Properties* - JVM level properties
3. *Environment Variables* - OS level variables
4. *Application Properties* - Application configuration
5. *Default Properties* - Framework defaults

=== Environment-Specific Overrides

Implement environment overrides:

[source,properties]
----
# application.properties
database.host=localhost
database.port=5432

# application-prod.properties
database.host=prod-db-server
database.port=5432
----

=== Dynamic Property Resolution

Configure dynamic property resolution:

[source,xml]
----
<configuration-properties file="application-${mule.env}.properties"/>
----

----
