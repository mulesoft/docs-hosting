= Managing Servers

Managing individual servers in your hybrid standalone environment involves monitoring, maintaining, and optimizing server performance and configuration.

== Overview

Server management includes:

* Starting, stopping, and restarting servers
* Monitoring server health and performance
* Updating server configurations
* Managing server resources
* Troubleshooting server issues

== Server Lifecycle Management

=== Starting and Stopping Servers

To manage server states:

1. Navigate to Runtime Manager
2. Select *Servers* from the left menu
3. Choose the server you want to manage
4. Use the available actions:
   * *Start* - Begin server operations
   * *Stop* - Halt server operations  
   * *Restart* - Stop and start the server

=== Server Status Monitoring

Monitor server status indicators:

* *Running* - Server is operational
* *Stopped* - Server is not running
* *Starting* - Server is in startup process
* *Stopping* - Server is shutting down
* *Error* - Server encountered an issue

== Configuration Management

=== Server Properties

Manage server-specific settings:

* Runtime version and updates
* Memory allocation settings
* Network configuration
* Security settings
* Environment variables

=== Configuration Updates

To update server configuration:

1. Select the server in Runtime Manager
2. Navigate to the *Settings* tab
3. Modify the required properties
4. Save changes
5. Restart the server if required
