= Monitoring Hybrid Standalone Instances

Monitor your hybrid standalone instances to ensure optimal performance, maintain system health, and enable proactive problem resolution across your distributed Mule runtime environment.

Runtime Manager provides comprehensive monitoring capabilities for your hybrid standalone infrastructure through integrated dashboards and alerting systems.

== Creating Alerts

Configure proactive monitoring through automated alerts that notify you of critical events, performance thresholds, and system anomalies.

* xref:creating-alerts-hybrid.adoc[Creating Alerts for Server, Server Groups or Clusters] +
Set up email notifications for critical events such as server downtime, high resource usage, application failures, or custom business metrics to enable rapid response to issues.


== Monitoring Dashboards

Monitor real-time and historical performance data for your servers, server groups, and clusters through comprehensive dashboards.

* xref:monitoring-dashboards-hybrid.adoc[Monitoring Dashboards for Server, Server Groups and Clusters] +
Track key performance indicators including CPU usage, memory consumption, JVM metrics, and application-specific statistics to understand system health and identify optimization opportunities.

[IMPORTANT]
When running Mule on Windows systems, the Mule service must be started by a user account that belongs to the *Performance Log Users* group to enable proper dashboard functionality.
