= Managing Schedulers

Managing schedulers in hybrid standalone environments involves configuring, monitoring, and maintaining scheduled jobs and automated processes within your Mule applications.

== Overview

Scheduler management includes:

* Creating and configuring scheduled jobs
* Managing scheduler execution and timing
* Monitoring scheduler performance and status
* Troubleshooting scheduler issues
* Implementing scheduler best practices

== Scheduler Types

=== Fixed Frequency Schedulers

Configure schedulers that run at fixed intervals:

* *Fixed Delay* - Delay between completion and next execution
* *Fixed Rate* - Fixed interval between execution starts
* *Initial Delay* - Delay before first execution
* *Time Unit* - Units for interval specification (seconds, minutes, hours)

=== Cron Expression Schedulers

Use cron expressions for complex scheduling:

* *Complex Timing Patterns* - Specific times and dates
* *Recurring Patterns* - Daily, weekly, monthly schedules
* *Business Hours* - Schedule within specific time windows
* *Multiple Execution Times* - Multiple times per day/week

=== Event-driven Schedulers

Configure schedulers triggered by events:

* *File-based Triggers* - Execute when files appear
* *Database Triggers* - Execute based on database changes
* *Message Queue Triggers* - Execute when messages arrive
* *API-triggered Scheduling* - Remote schedule control

== Scheduler Configuration

=== Basic Configuration

Configure basic scheduler settings:

[source,xml]
----
<scheduler doc:name="Fixed Frequency Scheduler" >
    <scheduling-strategy >
        <fixed-frequency frequency="30" timeUnit="SECONDS"/>
    </scheduling-strategy>
</scheduler>
----

=== Cron Configuration

Configure cron-based scheduling:

[source,xml]
----
<scheduler doc:name="Cron Scheduler" >
    <scheduling-strategy >
        <cron expression="0 0 8 * * MON-FRI" timeZone="America/New_York"/>
    </scheduling-strategy>
</scheduler>
----

=== Advanced Configuration

Configure advanced scheduler options:

== Scheduler Management in Runtime Manager

=== Viewing Schedulers

Access scheduler information:

1. Navigate to Runtime Manager
2. Select the target application
3. Click on the *Schedulers* tab
4. View scheduler status and configuration

=== Scheduler Controls

Manage scheduler execution:

* *Enable/Disable* - Control scheduler activation
* *Run Now* - Trigger immediate execution
* *View History* - Review execution history
* *Monitor Status* - Check scheduler health
* *Update Configuration* - Modify scheduler settings

=== Scheduler Status

Monitor scheduler states:

* *Enabled* - Scheduler is active and running
* *Disabled* - Scheduler is configured but not executing
* *Running* - Scheduler is currently executing
* *Error* - Scheduler encountered an error
* *Suspended* - Scheduler execution is temporarily suspended
