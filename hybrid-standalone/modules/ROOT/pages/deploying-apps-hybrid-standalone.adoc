= Deploying Mule Apps to Hybrid Standalone Instances

Deploying Mule applications to hybrid standalone instances provides the flexibility of on-premises deployment with cloud-based management capabilities.

== Overview

Application deployment to hybrid standalone instances involves:

* Preparing applications for deployment
* Selecting appropriate deployment targets
* Configuring deployment parameters
* Monitoring deployment progress
* Managing post-deployment validation

== Deployment Options

=== Target Selection

Choose from available deployment targets:

* *Individual Servers* - Deploy to specific server instances
* *Server Groups* - Deploy to all servers in a group simultaneously
* *Clusters* - Deploy to cluster members with high availability
* *Environment-based* - Deploy based on environment configurations

=== Deployment Strategies

Select appropriate deployment approaches:

* *Standard Deployment* - Direct deployment to target instances
* *Rolling Deployment* - Gradual deployment across multiple instances
* *Blue-Green Deployment* - Deploy to alternate environment sets
* *Canary Deployment* - Limited deployment for testing and validation

== Deployment Process

=== Using Runtime Manager

Deploy through the Runtime Manager interface:

1. Navigate to Runtime Manager
2. Select *Applications* from the left menu
3. Click *Deploy Application*
4. Choose the application file (JAR/ZIP)
5. Select deployment target:
   * Server, server group, or cluster
6. Configure deployment settings:
   * Application name
   * Environment variables
   * Properties
7. Review and confirm deployment
8. Monitor deployment progress

=== Deployment Configuration

Configure deployment parameters:

* *Application Name* - Unique identifier for the application
* *Runtime Version* - Target Mule runtime version
* *Resource Allocation* - CPU and memory allocation
* *Environment Variables* - Application-specific variables
* *Properties* - Configuration properties and settings

=== Advanced Deployment Options

Configure advanced settings:

* *Logging Configuration* - Log levels and output settings
* *Monitoring Settings* - Health check and monitoring configuration
* *Security Settings* - Authentication and authorization parameters
* *Scheduler Configuration* - Scheduled job settings
* *Network Configuration* - Port and endpoint settings
