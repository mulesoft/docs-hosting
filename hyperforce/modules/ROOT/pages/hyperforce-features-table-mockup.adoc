:page-noindex:

This page is an internal design prototype for W-22859080. It demonstrates two alternative layouts for the "Features Supported on Hyperforce" table to evaluate readability and scalability as more cloud regions are added.

== Option 1: Tabs Grouped by Geographic Region

Each tab groups related cloud regions together, reducing column count per view while keeping the full data set on one page.
