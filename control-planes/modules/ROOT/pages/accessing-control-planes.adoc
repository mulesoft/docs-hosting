= Accessing Anypoint Platform Control Planes
:page-aliases: eu-control-plane::platform-access-eu.adoc, eu-control-plane::studio-platform-access-eu.adoc, accessing-anypoint-clouds.adoc, anypoint-clouds::accessing-anypoint-clouds.adoc

Sign in to the Anypoint Platform control plane that holds your organization. Use the platform URL for the cloud MuleSoft provides for that geography. MuleSoft adds new regional clouds over time.

== Sign In or Sign Up

. Go to the platform URL for your cloud:
+
[%header%autowidth.spread]
|===
| Cloud | Platform URL

| US Cloud (default)
| https://anypoint.mulesoft.com[`anypoint.mulesoft.com`]

| EU Cloud
| https://eu1.anypoint.mulesoft.com[`eu1.anypoint.mulesoft.com`]

| Canada Cloud
| https://ca1.platform.mulesoft.com[`ca1.platform.mulesoft.com`]

| Japan Cloud
| https://jp1.platform.mulesoft.com[`jp1.platform.mulesoft.com`]

| India Cloud
| https://in1.platform.mulesoft.com[`in1.platform.mulesoft.com`]

| Australia Cloud
| https://au1.platform.mulesoft.com[`au1.platform.mulesoft.com`]
|===

. If you do not have an account in that cloud, click *Sign Up* and create one.
. Enter your username and password, then click *Sign In*.

To sign in from Anypoint Studio or Anypoint Code Builder, point the IDE at that control plane:

* xref:studio::hyperforce-configuration.adoc[Configure Anypoint Studio for Control Planes]
* xref:anypoint-code-builder::start-acb.adoc#change-clouds[Configure Anypoint Code Builder to a Different Control Plane]

Configuring Mule (`wrapper.conf` or `base_uri`) is a separate job for a running Mule instance. It is not required to sign in. See xref:configuring-mule-control-planes.adoc[Configuring Mule to Access Anypoint Platform Control Planes].
