= Anypoint Platform Control Planes Overview
:page-aliases: eu-control-plane::index.adoc, eu-control-plane::object-store-eu.adoc, anypoint-clouds::index.adoc, accessing-control-planes.adoc, eu-control-plane::platform-access-eu.adoc, eu-control-plane::studio-platform-access-eu.adoc, accessing-anypoint-clouds.adoc, anypoint-clouds::accessing-anypoint-clouds.adoc

Anypoint Platform control planes are the MuleSoft-managed environments where you design, deploy, and manage APIs and Mule apps. Each Anypoint Platform organization lives in exactly one cloud. Sign in to that control plane and deploy Mule apps to the runtime planes it supports.

For the full catalog of control planes (including MuleSoft Government Cloud and Anypoint Platform Private Cloud Edition (PCE)) and the control plane and runtime compatibility matrix, see xref:hosting-home::index.adoc[Anypoint Platform Hosting Overview].

== Control Plane Clouds

MuleSoft hosts a control plane in each supported geography and names that regional control plane a cloud, for example US Cloud or EU Cloud. US Cloud is the US control plane. EU Cloud is the EU control plane. **Cloud** is the product name of that isolated Anypoint Platform instance (login URL, organization, and data residency). **Control plane** is the management layer in that instance, as distinct from the xref:hosting-home::index.adoc#control-plane-and-runtime-plane[runtime plane], where apps run.

You choose one cloud for your organization. You don't choose a cloud and a control plane as two separate products.

* To create and deploy a Mule app, see xref:creating-and-deploying-mule-apps.adoc[Creating and Deploying Mule Apps].
* If you host Mule, or the app must use API gateway on a non-US Cloud, also see xref:control-plane-hostnames-allowlists.adoc[Control Plane Hostnames and Allowlists] and xref:configuring-mule-control-planes.adoc[Configuring Mule to Access Anypoint Platform Control Planes].

For data residency and compliance notes for each control plane, see xref:hosting-home::index.adoc#control-plane-hosting-options[Control Plane Hosting Options].

== Sign In to the Control Plane

Sign in to the Anypoint Platform control plane that holds your organization. Use the platform URL for that cloud. Organizations and user accounts are not shared across clouds. MuleSoft adds new regional clouds over time.

. Go to the platform URL for your cloud:
+
[%header%autowidth.spread]
|===
| Cloud | Platform URL

| https://anypoint.mulesoft.com[`US Cloud`]
| `https://anypoint.mulesoft.com`

| https://eu1.anypoint.mulesoft.com[`EU Cloud`] 
| `https://eu1.anypoint.mulesoft.com`

| https://ca1.platform.mulesoft.com[`Canada Cloud`]
| `https://ca1.platform.mulesoft.com`

| https://jp1.platform.mulesoft.com[`Japan Cloud`]
| `https://jp1.platform.mulesoft.com`

| https://in1.platform.mulesoft.com[`India Cloud`]
| `https://in1.platform.mulesoft.com`

| https://au1.platform.mulesoft.com[`Australia Cloud`]
| `https://au1.platform.mulesoft.com`
|===

. If you don't have an account in that cloud, click *Sign Up* and create one.
. Enter your username and password, then click *Sign In*.

To sign in from Anypoint Studio, the Anypoint Code Builder desktop IDE, Anypoint CLI, or Maven, configure that product to use the same control plane as your organization:
