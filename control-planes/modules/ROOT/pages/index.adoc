= Anypoint Platform Control Planes Overview
:page-aliases: eu-control-plane::index.adoc, eu-control-plane::object-store-eu.adoc, anypoint-clouds::index.adoc

Anypoint Platform control planes are the MuleSoft-managed environments where you design, deploy, and manage APIs and Mule apps. MuleSoft hosts a control plane in each supported geography and refers to that regional control plane as a cloud, for example US Cloud or EU Cloud. Each Anypoint Platform organization lives in exactly one control plane. Sign in, point Mule at that control plane, and deploy Mule apps to the runtime planes it supports.

For the full catalog of control planes (including MuleSoft Government Cloud and Anypoint Platform Private Cloud Edition (PCE)) and the control plane and runtime compatibility matrix, see xref:hosting-home::index.adoc[Anypoint Platform Hosting Overview].

== Control Plane Clouds

Use the platform URL for the control plane that holds your organization:

[%header%autowidth.spread]
|===
| Cloud | Platform URL

| https://anypoint.mulesoft.com[US Cloud] (default)
| `anypoint.mulesoft.com`

| https://eu1.anypoint.mulesoft.com[EU Cloud]
| `eu1.anypoint.mulesoft.com`

| https://ca1.platform.mulesoft.com[Canada Cloud]
| `ca1.platform.mulesoft.com`

| https://jp1.platform.mulesoft.com[Japan Cloud]
| `jp1.platform.mulesoft.com`

| https://in1.platform.mulesoft.com[India Cloud]
| `in1.platform.mulesoft.com`

| https://au1.platform.mulesoft.com[Australia Cloud]
| `au1.platform.mulesoft.com`
|===

For data residency and compliance notes for each control plane, see xref:hosting-home::index.adoc#control-plane-hosting-options[Control Plane Hosting Options].
