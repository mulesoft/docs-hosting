= Control Plane Hostnames and Allowlists
:page-aliases: eu-control-plane::servers-create-eu.adoc, anypoint-clouds::finding-endpoints-allowlists.adoc, finding-endpoints-allowlists.adoc

Use these hostnames when you allowlist outbound access to an Anypoint Platform control plane, when you pass `--region` to `amc_setup`, or when you set `anypoint.platform.base_uri` and `anypoint.platform.analytics_base_uri`. This table lists platform, analytics ingest, and Runtime Manager hosts for the commercial clouds.

When you set `anypoint.platform.base_uri` and `anypoint.platform.analytics_base_uri`, prefix the Platform URL and Analytics ingest hosts with `https://`. See xref:configuring-mule-control-planes.adoc[Configuring Mule to Access Anypoint Platform Control Planes].

For MuleSoft Government Cloud hostnames, see xref:hybrid-standalone::configure-ports-ips.adoc[Adding Ports, IPs, and Hostnames for Runtime Manager Agent] and xref:gov-cloud::index.adoc[MuleSoft Government Cloud Overview]. Anypoint Platform PCE uses the hosts you configure when you install PCE. See xref:private-cloud::index.adoc[Anypoint Platform PCE].

== Control Plane Hostnames

Allow outbound HTTPS (port 443) to these hosts, substituting the row for your cloud. Some Runtime Manager and ingest endpoints also use port 8443.

|===
| Cloud | Platform URL | Analytics ingest | Runtime Manager | `amc_setup --region`

| US Cloud (default)
| `anypoint.mulesoft.com`
| `analytics-ingest.anypoint.mulesoft.com`
| `runtime-manager.anypoint.mulesoft.com`
| Omit, or `prod`

| EU Cloud
| `eu1.anypoint.mulesoft.com`
| `analytics-ingest.eu1.anypoint.mulesoft.com`
| `runtime-manager.eu1.anypoint.mulesoft.com`

| `runtime-manager.ca1.platform.mulesoft.com`

Don't allowlist Anypoint Platform services by a single IP address. Some addresses are assigned dynamically and can change.
